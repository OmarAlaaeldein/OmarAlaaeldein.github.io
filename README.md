# Omar Alaaeldein — personal site

Single-page portfolio for [omaralaaeldein.github.io](https://omaralaaeldein.github.io/), served by GitHub Pages from `main` (`/`).

## Why

A lightweight, no-build showcase of work experience, open-source projects, skills, education, and publications — dark trading/terminal aesthetic, accessible markup, mobile-friendly nav.

## Local preview

Open `index.html` in a browser, or from this directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
